# @ixla/heso-darwin-arm64

macOS ARM64 (Apple Silicon) binary for heso. **Do not install directly** — install
[`@ixla/heso`](https://www.npmjs.com/package/@ixla/heso) and npm will
pull this package in as an optional dependency.

See [https://github.com/heso-inc/heso](https://github.com/heso-inc/heso) for the source.
